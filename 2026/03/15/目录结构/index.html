项目常见目录与 Git 忽略说明

发表于2026-03-15|更新于2026-04-02|随笔
|浏览量:

本文整理典型前端 / Node 项目里常见目录的含义，以及 .gitignore 里经常出现的条目在做什么。

常见项目目录

  • public/：存放静态文件，例如站点的 logo、favicon、无需打包就能直接访问的图片等，构建时通常会原样拷贝到输出目录。
  • node_modules/：依赖库目录，由 npm install 自动下载和生成，不需要手动修改，也不应该提交到 Git 仓库。
  • src/：源码目录，主要业务代码（组件、页面、样式、工具函数等）一般都放在这里。
  • index.html：项目入口 HTML 文件，打包工具会以它为模板，把打包后的 JS/CSS 自动注入其中。
  • package.json：项目配置和依赖声明文件，记录脚本命令（如 npm run dev）、dependencies 和 devDependencies 等信息。
  • package-lock.json / yarn.lock：依赖锁定文件，锁定每个包的精确版本，保证不同机器、不同时间安装到的依赖结果一致。

.gitignore 常见项参考

分类 被忽略的文件/文件夹 作用/解释
🖥️ 操作系统生成 .DS_Store macOS 系统自动生成的文件夹属性文件（如图标排列位置），纯个人偏好，无需上传。
📦 依赖包 node_modules/ 存放项目所有依赖的第三方库，体积巨大（通常几百 MB），且可通过 npm install 重新生成，必须忽略。
🗑️ 日志文件 npm-debug.log*、yarn-debug.log*、yarn-error.log*、**/*.log、selenium-debug.log 程序运行、包管理工具、测试工具产生的日志，记录错误信息，属于临时文件，无需备份。
🧪 测试产物 tests/**/coverage/、tests/e2e/reports 代码测试覆盖率报告和端到端测试报告，通常是运行时生成的 HTML 页面，无需纳入版本控制。
🧑‍💻 编辑器配置 .idea/、.vscode/、*.suo、*.ntvs*、*.njsproj、*.sln 不同 IDE 或编辑器的个人配置文件（如窗口布局、主题、调试设置），避免团队协作时互相覆盖和冲突。
🔒 本地隐私 *.local 通常指包含本地数据库密码、API 密钥等敏感信息的配置文件，绝对不能上传。
🚫 构建产物 # dist/（被注释） 该行被注释掉，表示 dist/ 不会被忽略；若取消注释则忽略打包产物。是否忽略取决于是否需要把构建结果也提交（如部署用）。
🔒 锁文件（特殊） package-lock.json、yarn.lock（常不忽略） 若在 .gitignore 里被注释或不写，则会上传。它们锁定依赖的精确版本，保证团队和线上环境一致，一般建议保留并提交。
